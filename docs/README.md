# Local LKE Documentation

Start with the [quick start](getting-started/quick-start.md) to run the complete
local application. The documentation is organized by purpose so conceptual
material, operating instructions, and historical implementation evidence do not
compete in one flat directory.

## Getting started

- [Quick start](getting-started/quick-start.md) — install, configure, test, and
  run Local LKE.
- [Chapter demos](getting-started/chapter-demos.md) — use the cumulative service
  or focus on one chapter.
